## 👨‍💻 About me

I build web applications and explore how **backend engineering, security and AI** can work together.

My repositories span music platforms, banking systems, healthcare applications, sports booking systems and computer vision.

- 🚀 **Build:** web interfaces, backend APIs and database-driven workflows.
- 🤖 **Explore:** Vietnamese emotion classification, face anti-spoofing and transaction graph analysis.
- 🧠 **Currently learning:** microservices, system design, Kafka and cloud deployment.
- 🔐 **Interested in:** backend architecture, security, distributed systems and applied AI.
- 🎯 **Goal:** build scalable systems where AI becomes part of real application workflows.
